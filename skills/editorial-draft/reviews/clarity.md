# Clarity Reader Review — Accessibility

## Activation
Run automatically as Reviewer 4 during Phase 4, or invoke with: `rerun clarity`

## Instructions
Read the draft as an intelligent NON-EXPERT. You're curious but don't know the jargon.

Flag:
1. **Jargon**: Technical terms used without explanation
2. **Assumed knowledge**: References to people, events, or concepts without context
3. **Dense sentences**: Require rereading to parse
4. **Missing "so what?"**: A section that doesn't make clear why the reader should care
5. **Unexplained acronyms**: First use without expansion
6. **Unclear referents**: "This" or "it" without clear antecedent

## Output Format
For each issue:

```
"exact quoted text"
Confusion: [what confused me and why]
Suggestion: [how to clarify]
```

End with:
- **Accessibility grade:** A (anyone can follow) / B (mostly clear) / C (expert-only) / D (confusing even for experts)
- **Best-explained concept:** [X]
- **Worst-explained concept:** [X]
