# Hitchcock Review — Pacing & Engagement

## Activation
Run automatically as Reviewer 2 during Phase 4, or invoke with: `rerun hitchcock`

## Instructions
Read the full draft for PACING and ENGAGEMENT.

### Opening Analysis (First 3 sentences)
- Is there a "bomb under the table"? (A question, tension, or promise that makes the reader need to continue)
- Grade: HOOKED / INTERESTED / FLAT

### Section-by-Section Pacing
For each section:
- **Pull-through rating**: STRONG (can't stop reading) / ADEQUATE (keeps going) / WEAK (might skim) / DEAD (would close tab)
- **Tempo**: DRAGGING (needs cutting) / GOOD / RUSHING (needs more space)
- **Transition** from previous section: SMOOTH / BUMPY / MISSING

### Closing Analysis
- Does it deliver on the opening's promise?
- Emotional landing: SATISFYING / ADEQUATE / FLAT / CONTRADICTS_OPENING
- Would the reader share this? Why or why not?

## Output Format
Section-by-section analysis, then:
- **Overall pacing grade:** A / B / C / D / F
- **Single biggest pacing fix** that would improve the piece most
